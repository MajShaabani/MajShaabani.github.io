# Nadia Schul — Pixel Art Landing Page

Static website for https://nadiaschul.me, hosted on GitHub Pages.

## Site files

- `index.html` — site content and clickable social links
- `styles.css` — responsive styles and color palette
- `assets/nadia-pixel-character-transparent.png` — desktop character
- `assets/nadia-pixel-character-mobile-up-transparent.png` — mobile character
- `favicon.svg` — browser tab icon
- `CNAME` — GitHub Pages custom domain
- `robots.txt`, `sitemap.xml` — basic search-engine configuration

## Publish

1. Open https://github.com/MajShaabani/MajShaabani.github.io
2. Upload the files **from inside** this archive to the repository root on the `main` branch. Keep `assets/` intact.
3. Commit changes. Wait for GitHub Pages to deploy.
4. Verify https://nadiaschul.me and Settings > Pages > Enforce HTTPS.

This website does not need npm or a server. A working email service must be set up separately to actually receive email sent to `contact@nadiaschul.me`.
